# Decks

Facts, numbers and claims come from the relevant division skill. Load it first:
a beautiful deck with wrong numbers is worse than no deck.

## Pick the tool
List the installed deck or presentation skills and choose the closest fit: a
general editorial skill for a clean premium look, a branded skill for a brand
the user owns, an editing skill for an existing deck. **Never put one brand's
identity on another's deck.** If no deck skill is installed, say so and build HTML.

## Build
1. Build the HTML or preview first, review it, then export to the final format.
2. One visual idea across the deck, real negative space, no text baked into images.
3. Render every slide and look at it before calling it done: no overflow, no
   clipped text.
4. Fonts must exist where the file is opened: embed them or send a PDF.

Short declarative titles, one accent colour, one idea per slide. Five sharp
slides beat fifteen dense ones.
