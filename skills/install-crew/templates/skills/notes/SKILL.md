# Notes

This files **the user's notes and outputs**, not the agent's own memory. "Remember
this for next time" belongs to the memory system, not here.

## Integration
{{INTEGRATION_SETUP}}

If no knowledge-base integration is wired, write the note to a clearly named
local Markdown file, say so, and tell the user what to connect.

## How to file
- One note, one topic, a title the future reader will search for.
- Date-stamp it and link related notes on first mention.
- Check for an existing note and update it rather than create a near-twin.
- Push to every configured destination unless told to use one.

**Output:** where the note now lives, for each destination.
