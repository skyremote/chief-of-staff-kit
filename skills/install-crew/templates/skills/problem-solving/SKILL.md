# Problem solving

1. **Name the actual decision.** It is often not the one stated.
2. Strip it to first principles before reaching for a known pattern.
3. Lay out the real options with honest trade-offs; state assumptions.
4. Quantify where you can. Rough is fine; label a guess as a guess.
5. **Recommend one**, say why, and say the one thing that would change your mind.

When a picture beats prose (option trees, system maps, decision matrices), use a
diagramming skill if one is installed; otherwise lay the map out in text.

For a genuinely high-stakes call, an independent second view is worth more than
a longer first one: ask a clean-window helper the same question without your
reasoning, then reconcile.
