# Voice scripts

- Short sentences, one idea per breath. Spoken rhythm beats written elegance.
- Write to time: about 150 words per minute. State the target length and hit it.
- Mark [pause], emphasis and pace where delivery depends on it.
- Lead with the hook; cut warm-up phrases.
- Spell for the mouth: numbers, acronyms and odd words as they are said.
- Match the speaker's real voice. Load the division skill's `voice.md` first.

If a voice or text-to-speech skill is installed, use it to audition the line.
If not, write the script and say plainly that no audio was produced.

**Output:** a timed script with delivery notes and an approximate runtime; flag
any line likely to be hard to deliver.
