# Program plan

## How to plan
- Break the goal into milestones, each with a **definition of done**.
- Order by dependency and critical path; do the unblocking thing first.
- Find the smallest shippable slice and ship it before polishing.
- Name the owner of each step and the one blocker that could derail it.
- Surface slippage early. A known delay beats a surprise; cut scope rather than
  miss a date silently.

## Output
A milestone list: step, owner, dependency, done line, rough effort. Keep it
where the workspace keeps live status, and update it in the same pass as the work.
Strategy and architecture calls are not made here: load `problem-solving` or
`architecture` for those.
